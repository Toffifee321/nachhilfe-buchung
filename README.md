# Tutoring Booking

A small web app for booking private tutoring sessions, built with Python, Flask and SQLite.

Teachers publish available time slots, students request them, and the teacher confirms or declines each request. Students can track the status of their bookings and withdraw pending requests.

## Features

- Simple slot management and request inbox for teachers
- Self-registration and booking overview for students
- Double bookings are prevented at the database level
- No external services, CDNs or trackers

## Tech Stack

- Python / Flask
- SQLite
- pytest for tests
